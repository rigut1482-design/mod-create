# Compact Rotation Speed Controller (NeoForge 1.21.1, Create 6.0.10)

One-block rotation speed controller. Shaft in on one side, out on the other, like a clutch.
Set the speed the same way as Create's regular controller: hold and drag or scroll on the dial, range -256 to 256 rpm.

Texture: run `python3 tools/make_texture.py` to regenerate the 16x16 brass texture.
